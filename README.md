# Welcome!

This project aims to answer several questions using a variety of SQL clauses, ranging from CASE WHEN to Window functions.
The entire code is within the Project-code file, with some context provided through the comments. There's also a bonus insight called "Finding Susan" which showcases some critical thinking skills, as well as reasoning explaining why certain joins are used over others.
The results are provided in screenshots, and can be double-checked by loading the databases from the code provided in the source folders. These folders also contain schema diagrams and licences.

Some of the questions use the Pagila database, an online films rental shop. This database was obtained via Devrim Gündüz at [https://github.com/devrimgunduz/pagila](https://github.com/devrimgunduz/pagila/tree/master).
Other questions use data from the famous Northwind database, an international gourmet food distributor. This database originates from Microsoft and is adapted for PostgreSQL via <https://github.com/pthom/northwind_psql/tree/master>

The project was created using PostgreSQL and pgAdmin4.

Thanks for coming around!
